# bloomia-previews
Section thumbnails for the Bloomia Salla theme (served by jsDelivr) — صور معاينة أقسام ثيم بلوميا

Each image is a real capture of the section, rendered from the theme itself (1280px, reduced motion),
fitted in a 634×600 frame on the theme's page colour. `twilight.json` links them by commit through
`https://cdn.jsdelivr.net/gh/fadisowan/bloomia-previews@<commit>/bloomia-<section>.png`.
